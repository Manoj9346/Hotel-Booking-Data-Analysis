# Hotel Booking Data Analysis

## Project Overview
This project analyzes hotel booking data using Microsoft Excel to identify booking patterns, customer trends, revenue-related insights, and other useful business observations.

## Tools Used
- Microsoft Excel
- Excel Tables
- Sorting & Filtering
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Charts

## Project Work
- Original data copied and preserved
- Cleaned and organized data
- Converted cleaned data into an Excel Table named `Hotel_Data`
- Performed formula-based analysis
- Created Pivot Tables
- Generated insights from the dataset
- Created project documentation

## Files
- `Hotel_Booking_Data_Analysis.xlsx` – Complete Excel analysis
- `Project_Documentation.docx` – Project documentation

## Objective
The objective of this project is to analyze hotel booking data and derive meaningful insights using Excel.
